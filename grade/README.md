# 导航作业 70 分自动评分器

评分器自动执行以下流程：启动 `bash/sim_nav_all_start.sh`，等待 15 秒，确认目标话题至少有两个订阅者且机器人 TF 可用，在 `/goal_pose` **只发布一次**固定终点 `(14.1, 14.1)`，随后计时并以 20 Hz 采样机器人位姿。

目标发布使用 ROS 2 `Reliable` QoS：已经匹配的订阅者发生传输丢包时，由 DDS 层自动重传，不需要评分器反复发布。目标发布后还必须在 10 秒内收到首条有效 `/global_path`，它作为“导航已经处理目标”的应用层确认；否则明确报错并终止，不重复目标，避免二次导航影响公平性。

计时起点是评分器调用一次 `/goal_pose` 发布的瞬间，因此包括全局规划耗时。只有机器人距离目标不超过 0.20 m、`/Odometry` 平移速度不超过 0.05 m/s，并连续保持 0.50 秒，才确认到达。终点计时取首次同时满足距离和速度条件的时刻。

## 使用

在项目根目录执行：

```bash
chmod +x grade_nav.sh
./grade_nav.sh
```

若项目已经启动，可跳过启动和 15 秒等待：

```bash
./grade_nav.sh --no-start
```

每次结果保存在 `grade/results/日期_时间/`：

- `result.json`：分项得分、总分、统计量和本次阈值；
- `trajectory.csv`：每个位姿采样及其目标距离、路径误差；
- `report.txt`：适合直接查看或归档的中文评分单；
- `tracking_error.svg`：蓝色全局参考路径、按误差着色的实际轨迹、误差随时间的曲线，以及满分线和零分线。SVG 可直接用浏览器打开。

运行期间终端每 2 秒打印一次：已用时间、当前位姿、距目标距离、当前速度和当前路径误差。收到路径时会打印路径点数；结束后还会打印判定到达时速度、规划确认耗时、误差 mean/P95/max、满分误差线内采样占比、参考路径和实际轨迹长度、路径长度比及平均速度。

评分结束后，仿真与 RViz 窗口保持运行，便于检查；关闭对应终端窗口即可结束项目。

## 默认评分标准

三个分项之间独立评分，总计 70 分。脚本会在发送目标前把以下标准完整打印到终端。区间内均采用线性插值，最终保留两位小数。

| 分项 | 满分条件 | 线性扣分区间 | 零分条件 | 说明 |
|---|---:|---:|---:|---|
| 准确到达（25） | 最终距离 ≤ 0.20 m | 0.20–1.00 m | ≥ 1.00 m | 最终 `map→base_link` 位置到目标的欧氏距离 |
| 时间（25） | 用时 ≤ 45 s | 45–120 s | ≥ 120 s | 从发布目标到首次同时满足距离和速度条件；未到达直接为 0 分 |
| 跟踪精度（20） | RMSE ≤ 0.10 m | 0.10–0.50 m | ≥ 0.50 m | 采样位置到首条有效 `/global_path` 折线的最短距离的均方根 |

为避免“高速掠过终点”或噪声造成误判，到达必须同时满足：距离 ≤ 0.20 m、平移速度 ≤ 0.05 m/s，并连续保持 0.50 秒。计时取首次同时满足两个条件的时刻。最终距离使用确认到达时的实际位置计算，继续用于“准确到达”25 分评分。默认总超时为 150 秒。若目标发布后 10 秒内没有收到有效全局路径，本次评测以 `no_global_path` 结束。

对应公式（`clamp(v, 0, M)` 表示把分数限制在 0 到满分）：

```text
准确到达 = clamp(25 × (1.00 - 最终距离) / (1.00 - 0.20), 0, 25)
时间     = 到达 ? clamp(25 × (120 - 用时) / (120 - 45), 0, 25) : 0
跟踪精度 = clamp(20 × (0.50 - RMSE) / (0.50 - 0.10), 0, 20)
```

各项在“满分条件”以内直接取满分。

## 调整评测参数

默认阈值都能通过命令行覆盖。例如：

```bash
./grade_nav.sh --timeout 180 --time-full 50 --time-zero 140
```

若某个精简版本的项目确实只有一个目标订阅者，可显式调整发现条件；路径确认仍然保留：

```bash
./grade_nav.sh --min-goal-subscribers 1 --path-timeout 15
```

到达速度阈值也可以调整，例如改为 0.08 m/s：

```bash
./grade_nav.sh --arrival-speed-threshold 0.08
```

查看全部参数（项目需已启动）：

```bash
./grade_nav.sh --no-start --help
```

启动等待时长也可通过环境变量修改，但正式评测建议保留 15 秒：

```bash
GRADE_STARTUP_WAIT=20 ./grade_nav.sh
```
